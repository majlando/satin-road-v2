## Concept: Satin Road

### User story / feature requirements:

- As a website administrator it should be possible to manage categories of products (drugs, weaponry, stolen artifacts, etc)

- As a user it should be possible to create listings for products and manage inventory + buy products from other users

### Hard stories that will reward a mystery prize:

- If more than 10 orders is placed on a single vendor by a user, the next order prize will be reduced by 20%

- If a vendor has sold more than 100 orders they will be featured on the top of the listings / landing page

- For every purchase there's a 1% chance the buyer is FBI and the vendor will be shut down permanently / their products will be removed from Satin Road

Any feature that you think is nice to have on an ecommerce site (of this nature) is welcome! Creativity is encouraged.
