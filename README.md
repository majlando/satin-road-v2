## Satin Road

A fictional marketplace.

### How to Run

```bash
docker compose up --build
```

Open <http://localhost:8080>. The API's documentation is at
<http://localhost:8080/swagger>.

Log in as `admin` with the password `password`. Every demo user (`shadypete`,
`grandmasoap`, `loyalbuyer`, ...) has that same password, or create your own
account from the login page. Logins are kept in a cookie whose signing keys
live on the data volume, so restarting the API keeps everyone logged in.

The `users` table gained a `password_hash` column. There are no migrations, so
a database from before login must be reset (below) before it can be logged into.


Reset all data:

```bash
docker compose down -v
```

For development, run the API and the web app separately:

```bash
dotnet run --project src/SatinRoad.Api          # http://localhost:5080
cd web && bun install && bun run dev            # http://localhost:3000
```

### Tech stack

.NET 10 API (ASP.NET Core, linq2db, SQLite, OpenAPI and Swagger), React web
app built with Bun and a client generated by swagger-typescript-api, xUnit
tests, Docker Compose with nginx in front.

### Testing

```bash
dotnet test
```

The business rules (discount, FBI raid, featured vendors) were built with
Test Driven Development: tests first, then the code. The API was tested after
each endpoint was written (Test Last).
