# Satin Road

A fictional marketplace.

## How to Run

```bash
docker compose up --build
```

Open <http://localhost:8080>. The API's documentation is at
<http://localhost:8080/swagger>.

The Docker setup runs in production mode, with two things deliberately left
on for grading and the demo: the **demo data** (`Seed__Demo` in
`docker-compose.yml`) and **Swagger**. For a real deployment you would set
`Seed__Demo` to `false` and remove Swagger. The raid chance can be changed
without rebuilding: `FBI_RAID_CHANCE=1 docker compose up` makes every purchase
a raid.

Reset all data (an FBI raid is permanent):

```bash
docker compose down -v
```

For development, run the API and the web app separately:

```bash
dotnet run --project src/SatinRoad.Api          # http://localhost:5080
cd web && bun install && bun run dev            # http://localhost:3000
```

## Tech stack

.NET 10 API (ASP.NET Core, linq2db, SQLite, OpenAPI and Swagger), React web
app built with Bun and a client generated by swagger-typescript-api, xUnit
tests, Docker Compose with nginx in front.

```bash
dotnet test
```
